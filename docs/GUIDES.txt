SOLID PRINICPLES Implementation in the projext

SINGLE RESPONSIBILITY PRINCIPLE:

-> UserPersistenceMapper is only responsible for mapping the user entity to the database
->UserMapper is only responsible for mapping the user entity to the dto
->prisma.client is only responsible for initializing the database connection
->UserRepository is only responsible for database operations
->UserRegisterController is only responsible for receiving http request, extracting data from the req body, passing it to the corresponding use case and formatting respone to json



OPEN CLOSED PRINCIPLE:

-> IbaseRepository can be used to create new repository types without changing the base interface
->httpstatus coede enum alow adding new status code without breaking current once.

Interface segregation principle

Dependency Inversion Principle
